# ENGINEERING BIBLE

## Engineering Philosophy

Maintainable.

Modular.

Reusable.

---

# Backend Rules

Do not modify working backend logic unless required.

Avoid unnecessary architecture changes.

Keep AI output structured.

---

# Frontend Rules

Do not replace Streamlit widgets with static HTML.

Use reusable components.

Keep layouts responsive.

Maintain consistent spacing.

---

# Claude Rules

Always explain changed files first.

Return complete files.

No snippets.

No placeholder code.

Ask before making product decisions.

Do not invent backend fields.

Do not silently redesign pages.
